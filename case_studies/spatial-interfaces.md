### The Challenge
With the rise of spatial computing, design is transitioning from flat screens to infinite, three-dimensional spaces. This exploration probes how depth, physical lighting, and hand gestures can be utilized to make spatial layouts intuitive without causing user fatigue.

![3D Spatial UI Concept](artifacts/projects/project_compact_1781015914671.png)

### The Experiment
Using physical shadows, volumetric lighting, and depth layers, we prototyped responsive menus that float in the user's environment. The key was to ensure the interface reacts dynamically to where the user's gaze is directed, creating a soft focus effect.

### Findings
- **Depth as Hierarchy:** Utilizing Z-axis distance to stack secondary information layers rather than hiding them.
- **Interactive Depth Cues:** Subtle scaling and glow effects when elements are focused or selected.
- **Natural Physics:** Incorporating inertia and soft bounces for scrolling in a 3D environment.
